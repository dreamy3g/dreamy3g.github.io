1. 개요

두두의 동화나라(이하 "앱")는 아이의 일상을 AI 동화로 만들어주는 서비스예요. 개인정보를 최소한으로 수집하며, 아이의 소중한 추억을 안전하게 보호해요.

2. 수집 또는 처리하는 정보

  • 동화 생성 시 입력한 내용 — AI 동화 생성 목적으로만 OpenAI API에 전달되며 서버에 저장되지 않아요.
  • 아이 이름 — 기기에만 저장되며 외부로 전송되지 않아요.
  • 생성된 동화 — 기기 내부 저장소에만 저장돼요.
  • Firebase 익명 인증 — 개인 식별 정보 없이 서비스 운영에 사용돼요.
  • 광고 기능 동작을 위한 Google Mobile Ads SDK 관련 정보

3. 정보의 이용 목적

  • AI 동화 생성
  • 동화 앨범 저장 및 관리
  • 앱 설정값 저장 (동화 길이, TTS 속도, 목소리 등)
  • 광고 기능 제공

4. 정보의 보관 방식

생성된 동화와 설정값은 사용자 기기에만 저장돼요. 앱 삭제 시 기기에 저장된 모든 데이터가 함께 삭제돼요. 내보내기 기능으로 백업한 파일은 직접 관리해주세요.

5. 제3자 서비스

  • Firebase (Google) — 익명 인증 및 서비스 운영
  • OpenAI API — 동화 생성. 입력 내용이 OpenAI 서버로 전달돼요. OpenAI 개인정보처리방침
  • Google AdMob — 광고 제공. Google 개인정보처리방침

6. 아동의 개인정보 보호

두두의 동화나라는 아동을 위한 앱으로, 아동의 개인정보를 직접 수집하지 않아요. 보호자가 앱을 관리해주세요.

1. Overview

Dudu's Story Land (the "App") turns children's daily moments into AI-generated stories. We collect minimal personal information and protect your child's precious memories.

2. Information We Process

  • Story input text — sent to OpenAI API for story generation only; not stored on our servers.
  • Child's name — stored on device only; never transmitted externally.
  • Generated stories — stored in device local storage only.
  • Firebase anonymous authentication — used for service operation without personal identification.
  • Information related to ad delivery via Google Mobile Ads SDK.

3. Purpose of Use

  • AI story generation
  • Story album storage and management
  • Saving app settings (story length, TTS speed, voice, etc.)
  • Providing advertising features

4. Data Storage

All stories and settings are stored only on the user's device. Deleting the app removes all locally stored data. Please manage any files exported via the backup feature yourself.

5. Third-Party Services

  • Firebase (Google) — anonymous authentication and service operation.
  • OpenAI API — story generation. Input content is sent to OpenAI servers. OpenAI Privacy Policy
  • Google AdMob — ad delivery. Google Privacy Policy

6. Children's Privacy

Dudu's Story Land is designed for children. We do not directly collect personal information from children. Parents or guardians are responsible for managing app usage.
