매일매일 방탈출 운영팀은 앱과 웹판의 데이터를 아래와 같이 처리합니다.

기기에 저장하는 정보

진행 상태, 탈출 기록, 연속 기록, 즐겨찾기, 최근 검색어와 설정이 앱 또는 브라우저에 저장됩니다. 검색어는 기기에서 검색에만 사용합니다. 앱은 회원가입을 요구하지 않으며 기기 간 기록 동기화를 제공하지 않습니다.

서버로 전송하는 정보와 목적

탈출이나 시간 초과 결과 또는 별점을 처음 보낼 때 서버가 생성한 익명 기기 식별값과 인증용 토큰을 사용합니다. 서버는 방 ID, 결과 유형, 플레이 시간, 힌트와 오답 횟수, 별점, 접수 시각을 처리합니다. 이 데이터는 결과와 별점을 접수하고 같은 식별값의 방별 별점을 갱신하며 클리어율·평균 시간·별점 통계를 계산하는 데 사용합니다. 다른 플레이어에게는 방별 집계 수치가 표시됩니다.

방과 정책 페이지를 불러오거나 API를 이용하는 과정에서 IP 주소 등 연결 정보가 처리될 수 있습니다. IP 주소는 API 요청 횟수를 제한하는 데도 사용합니다. 현재 앱과 웹판은 제3자 광고 또는 앱 분석 SDK를 통해 이용 데이터를 수집하지 않습니다.

알림

알림을 허용하면 앱은 받아 둔 방 공개 목록과 기기에 저장된 탈출 기록으로 새 방과 연속 기록 알림을 기기에 예약합니다. 앱 설정에서 종류별로 끄거나 운영체제 설정에서 알림 권한을 변경할 수 있습니다.

외부 서비스 및 국외 처리

  • DigitalOcean은 미국에서 API와 통계용 데이터베이스를 호스팅합니다.
  • Cloudflare는 방 콘텐츠와 공개 통계를 전송하고 비공개 서버 백업을 저장합니다.
  • GitHub Pages는 정책 페이지를 호스팅합니다. 글꼴이 기기에 캐시되지 않은 경우 Google Fonts에서 내려받을 수 있습니다.

이 서비스들의 인프라 위치에 따라 접속 정보 또는 해당 서비스가 맡은 데이터가 국외에서 처리될 수 있습니다.

보관, 삭제 및 권리 행사

기기 기록은 앱 설정의 ‘이 기기 기록 초기화’ 또는 브라우저의 사이트 데이터 삭제로 지울 수 있습니다. 운영체제 백업은 기기와 계정 설정에 따릅니다. 기기 기록을 지워도 이미 서버로 보낸 결과와 별점은 별도로 남습니다.

현재 테스트판에서 서버 기록은 통계와 장애 복구를 위해 보관되며 자동 만료일은 설정돼 있지 않습니다. 서버 백업은 비공개로 보관합니다. 기록의 열람, 정정, 삭제 또는 처리 제한 요청은 아래 문의처에서 접수합니다. 요청 대상 기록을 확인할 수 있는 범위에서 처리하며, 백업에 있는 데이터는 해당 백업이 삭제될 때까지 남을 수 있습니다.

Privacy Policy

Effective November 27, 2026

The Daily Escape team handles data from the mobile app and web version as described below.

Data stored on your device

Game progress, escape records, streaks, bookmarks, recent searches, and preferences are stored in the app or browser. Search queries are used for on-device search. Daily Escape does not require an account or provide cross-device progress sync.

Data sent to the server and why

When you first send an escape or timeout result or submit a rating, the service uses a randomly assigned device identifier and an authentication token. The server processes the room ID, outcome, play time, number of hints and wrong answers, rating, and submission time. It uses these data to accept results, update the rating for a room and device identifier, and calculate completion rates, average escape times, and ratings. Other players see aggregated room statistics.

Connection information such as IP addresses may be processed when you load rooms or policy pages or use the API. The API also uses IP addresses to limit request rates. The current app and web version do not use third-party advertising or app analytics SDKs to collect usage data.

Notifications

If you allow notifications, the app uses the downloaded release schedule and the escape dates saved on your device to schedule new-room and streak reminders locally. You can turn off either type in the app or change notification permission in system settings.

Service providers and international processing

  • DigitalOcean hosts the API and statistics database in the United States.
  • Cloudflare delivers room content and public statistics and stores private server backups.
  • GitHub Pages hosts the policy pages. The app may download fonts from Google Fonts if they are not already cached on your device.

Connection information and the data handled by each provider may be processed outside your country, depending on the provider’s infrastructure.

Retention, deletion, and your rights

You can erase device records using “Reset records on this device” in the app or by clearing the site’s data in your browser. Operating system backups depend on device and account settings. Resetting device records leaves any results and ratings previously submitted to the server in place.

The current test version retains server records for statistics and recovery. It has no automatic expiration schedule. Server backups are stored privately. Contact us to request access, correction, deletion, or restriction of processing. We handle requests to the extent that we can verify the records in question. Data in backups may remain until the corresponding backup is deleted.

Contact and changes

For support or privacy requests, email dailyescape.playmi@gmail.com. We post updates to this policy on this page.
